How to use, privacy & limits

1. Capture and sanitize screenshots using your existing capture tool. 2. Add PNG/JPEG files (file-picker order is preserved; reorder explicitly if needed). 3. Write titles and instructions; optionally click each image for one numbered marker. 4. Save project JSON to keep editing later. 5. Export guide HTML and open that file in Chrome/Edge; use its Print / Save as PDF button for browser printing. StepDesk does not directly generate a PDF file.

One guide per workspace, up to 3 steps. Each imported image: at most 5 MiB, at most 16 million pixels, at most 1,600 pixels after resize. Total project: at most 24 MB encoded image data. JSON restore: at most 26 MiB. Imports are validated before replacing the project. No autosave, cloud, account, live capture, AI text generation, team sync, password protection or encryption. Exported HTML embeds the images and text, so inspect everything before sharing. Project JSON contains the working images too. Markers are not redaction. No competitor code, branding or templates are included.
